## 2. Die 10 Leit-Adjektive (Markenkern)

Das „Gesetz" der Marke. Sie definieren Mensch, Code und Design gleichermaßen und müssen
ohne Erklärung spürbar sein.

1. **Fundiert** — Alles hat Standfüße, keine Luftschlösser. Die Basis: alles hat Gewicht
   und Tiefe, im Layout wie in der Architektur.
2. **Scharfsinnig** — Erkennt Lücken. Setzt die Lichtpunkte in komplexen Systemen, arbeitet
   mit hohen Kontrasten und präzisen Details.
3. **Authentisch** — Kein Verstellen, kein Grau-in-Grau. Im Code heißt das: keine Fassaden,
   sondern ehrliche, belastbare Architektur.
4. **Charakterstark** — Mut zum Unkonventionellen. Eigene Kanten statt geglätteter
   Austauschbarkeit.
5. **Nuanciert** — Sieht Details in Code und Fotografie. Verlangt feine Abstufungen statt
   plakativer Extreme.
6. **Autonom** — Eigenständige Lösungen. Als Solo-Traveler ein eigenes Layout fernab vom
   IT-Einheitsbrei — kein Template-Look.
7. **Direkt** — Kommunikation ohne Masken. Klare Hierarchien, prägnante, schnörkellose
   Sprache und Typografie.
8. **Wachsam** — Radar für Atmosphäre und Stabilität. Fängt die Stadt ein und bringt Leben
   in sterile Technik.
9. **Substanziell** — Die Arbeit fühlt sich an wie schwerer Wollstoff: haptisch, wertvoll,
   von bleibender Bedeutung.
10. **Stilsicher** — Die meisterliche Klammer, die Backend-Logik und Ästhetik zu einem
    harmonischen Ganzen vereint.

## 4. Zielgruppe & Abgrenzung

| Kriterium     | Beschreibung                                                                           |
| ------------- | -------------------------------------------------------------------------------------- |
| **Branche**   | Unternehmen mit komplexen Systemen (z. B. Landwirtschaft, E-Commerce, B2B-Plattformen) |
| **Bedürfnis** | Sicherheit, Stabilität, Skalierbarkeit — keine „Quick & Dirty"-Lösungen                |
| **Werte**     | Substanz über Schein, Handwerk über Fließband, Authentizität über Template             |
| **Beispiel**  | „Das Amazon für Landwirte" — massive Plattformen mit kritischem Backend                |

Die Website bedient dabei **ein Hub, zwei Publika**: Hiring Manager und Recruiter, die
Senior-/Staff-Backend-Kompetenz prüfen, sowie Menschen, die über die Street Photography
kommen. Jede Seite muss für beide funktionieren.

| Wettbewerber         | Deren Ansatz                    | Der eigene Ansatz                                   |
| -------------------- | ------------------------------- | --------------------------------------------------- |
| Standard-Agenturen   | Template-Lösungen, Grau-in-Grau | Eigenständig, warme Farbwelt, editorialer Charakter |
| Freelancer (günstig) | „Ich code alles"                | „Ich architektoniere Backbones"                     |
| Tech-Nerds           | Nur Code, keine Ästhetik        | Code + Street Photography + Kultur                  |
| Designer             | Nur Optik, keine Tiefe          | Ästhetik als Beweis für Präzision                   |

## 5. Persönliche Identitäts-Elemente

Herkunftsgeschichte, nicht Design-Vorgabe — sie erklärt, woher die Haltung kommt.

| Element                      | Beschreibung                                          | Relevanz für die Positionierung                  |
| ---------------------------- | ----------------------------------------------------- | ------------------------------------------------ |
| **London Solo-Trip**         | Erstes Mal allein reisen, Hostel, Fremde kennenlernen | Beweis für Autonomie & Präsenz                   |
| **Hamburg-Schanze**          | Safe Space, Trubel, Street Photography                | Urbane Verankerung, Ästhetik                     |
| **Minecraft / Craft Attack** | Verbindung zu einer neuen Bezugsgruppe                | Connecten über Systeme & Inhalte                 |
| **Unfertige Projekte**       | Klassisches Typ-5-Muster                              | Wachstumsziel: Integration zur 8 (Fertigstellen) |

**Kleidungsstil** — grüner Wollmantel statt Bomberjacke, rosa Schuhe, sichtbare weiße
Socken: Kontrast und Mut zur Farbe als gelebte Haltung, nicht als Verkleidung.

**Musik** — German Indie (Jeremias, Provinz, Betterov) für den Wollmantel-Vibe, Cloud Rap
(Pashanim, Symba, Ski Aggu) für den Schanze-Vibe. Verbindet Handwerk mit urbaner Kultur.

**Bildsprache** — echte Street Photography aus Schanze, London und Hamburg, hoher Kontrast,
bewusstes Licht. Niemals Stockfotos.

## 6. Visuelle Identität (wie umgesetzt)

Kurzfassung des tatsächlich ausgelieferten Systems. **Details und Code-Rezepte:
`CLAUDE.md` → Design System.**

- **Typografie:** Instrument Serif (Display) + Instrument Sans (Fließtext) + IBM Plex Mono
  (Labels, Meta, Eyebrows).
- **Farben:** Forest Green `#357056` (Primary), Amber `#e89234` (Secondary/Warm),
  warme Cream-Flächen `#f7f2e5`, sparsamer Flieder-Akzent `#8c7ad6`.
- **Grundfläche:** Cream — **nicht** Grün. Grün und Forest Dark sind Akzentflächen
  (Footer, Kontakt-Sektion, Context-Panel).
- **Form:** Runde Ecken, geschichtete warme Schatten, taktile Karten, leichte Tilts.
  Editorial statt Generic-SaaS, warm statt korporativ.
- **Modus:** Light Mode only, WCAG AA als Untergrenze, `prefers-reduced-motion` respektieren.
